# Aanvullend IW5-resourceherstel (testpakket)

Download **alle ZIP-delen** uit deze map. Het zijn zelfstandige ZIP-bestanden,
geen multipart-RAR. Ze bevatten samen het volledige aanvullende herstelpakket.

Sluit Plutonium en maak eerst een backup van je hele `storage/iw5`-map.
Pak elk deel uit in dezelfde actieve `Plutonium/storage/iw5`-map.
Kies **overslaan** als Windows vraagt bestaande bestanden te vervangen.
De dubbele LEESMIJ en controledocumenten hoef je maar eenmaal te bewaren.

De 577 originele ontbrekende afbeeldingen/geluiden, 77 scripts en twee fastfiles
zijn tegen de officiële release gecontroleerd. Bestaande afwijkende bestanden
zijn niet vervangen. De oorspronkelijke mod/launcher hoeft niet opnieuw te
worden geïnstalleerd. Dit pakket bevat geen executable of commandobestand.

Geen bevestigde complete oplossing: bestaande versieverschillen zijn behouden;
Windows/gameplay en Defender zijn niet getest. Omzeil een scannerblokkade niet.
Probeer daarna `loadmod survival` en deel een volledig console.log bij fouten.
